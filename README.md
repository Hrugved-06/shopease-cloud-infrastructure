# ShopEase Cloud Infrastructure Planning

## Project Overview

ShopEase is a fictional e-commerce platform designed to demonstrate cloud infrastructure planning using Amazon Web Services (AWS).

The project focuses on designing a scalable, secure, highly available, and cost-effective cloud architecture for an online shopping platform.

## AWS Services Used

- Amazon Route 53
- Amazon CloudFront
- Application Load Balancer
- Amazon EC2
- EC2 Auto Scaling
- Amazon RDS MySQL
- Amazon S3
- Amazon VPC
- AWS IAM
- Security Groups
- Amazon CloudWatch
- AWS Backup

## Key Features

- Scalable application infrastructure
- Load balancing
- Auto Scaling
- Multi-AZ architecture
- Secure private database
- Cloud monitoring
- Backup and disaster recovery
- Cost optimization strategy
- Risk assessment

## Architecture

The proposed architecture follows the flow:

User → Route 53 → CloudFront → Load Balancer → EC2 → RDS / S3

The EC2 instances are managed using Auto Scaling and deployed across multiple Availability Zones.
